# QuickNotes

QuickNotes is a simple and responsive note-taking web application built with HTML, CSS and JavaScript. It allows users to create notes, organize them into Personal, Work and Study categories, search through their notes, delete individual notes and keep their notes saved in the browser using localStorage.

## Features

- Add notes with a maximum length of 200 characters
- Categorize notes as Personal, Work or Study
- Display the date and time each note was created
- Delete individual notes
- Search notes using case-insensitive text matching
- Validate empty notes
- Validate notes longer than 200 characters
- Display the correct number of saved notes
- Save notes to localStorage
- Restore notes after refreshing the page
- Responsive layout for mobile and desktop screens
- Category-specific styling
- Clean and accessible HTML structure
